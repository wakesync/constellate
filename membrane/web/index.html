PROTOTYPE, NOT PERSONAL ONBOARDING The demo uses an isolated synthetic backend, with no LLM. Access toggles change membership in a fresh fixture, not persistent revocation.

What is still in development?

H200 Qwen inference was not working at the last check. Mac and Darkbloom inference are proposed, not connected. Scoped credentials, persistent revocation and personal-agent onboarding are not ready. Memory protection does not make an external model private.
